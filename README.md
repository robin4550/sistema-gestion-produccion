# sistema-gestion-produccion
# Sistema Web de Gestión de Producción

Sistema web para la gestión y control de producción de una empresa metalmecánica.

> Proyecto académico, Actividad 4 de Calidad de software.
> Autor: Robinson Damian Rodríguez Rodríguez
> Corporación Universitaria Iberoamericana, Ingeniería de Software, Bogotá D.C.

## Descripción del problema

Las empresas del sector metalmecánico necesitan controlar sus procesos de producción, materias primas, inventario y órdenes de trabajo. En muchos casos esto se hace con registros manuales u hojas de cálculo no integradas, lo que genera pérdida de información, errores de registro y retrasos en la toma de decisiones.

## Solución propuesta

Un sistema web que centralice la información de productos, materias primas, inventario y órdenes de producción, y genere reportes básicos para apoyar la toma de decisiones.

## Funcionalidades

- Registrar, consultar, actualizar y eliminar productos
- Registrar materias primas y consultar existencias
- Registrar órdenes de producción, consultar y actualizar su estado
- Registrar productos terminados
- Consultar información de producción y generar reportes básicos
- Administrar usuarios según su rol

## Restricciones

- Prototipo académico
- Orientado a una empresa metalmecánica pequeña o mediana
- Sin integración con sistemas contables ni con maquinaria industrial
- Sin aplicación móvil en la primera versión
- Requiere conexión de red para acceder a la plataforma
